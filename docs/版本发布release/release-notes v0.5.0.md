## 鼠标主题工具 v0.5.0

一个**不需要管理员权限**的 Windows 光标主题管理器：导入 `.zip` / `.themepack` / `.theme` 主题包 → 一键应用 → 管理 → 回溯上次用的那个。

### ✨ v0.5.0 更新了什么

- **Ctrl+K 快速切换主题**：任何页面按 `Ctrl+K`，输入名称即过滤，回车直接应用——「挑一个 → 应用」从四五步缩到两步；面板底部还有「还原系统默认光标」，跟随托盘快速切换同一套链路
- **右键菜单来了**：主题图库卡片与「我的主题」表格行右键即可应用 / 导出 / 重命名 / 删除，不用先选中再找检查器；使用中的主题会说明为什么不能删
- **主题描述可编辑**：检查器里点铅笔给主题写一句话描述（最多 200 字），导入时是「导入自 xxx.zip」，现在可以改成你自己的备注
- **批量整理支持「导出所选」**：勾选要清理的主题后先导出一份留底、再删除，清理不再需要「先全量导出」；与「导出全部」共用一套部分成功语义
- **键盘可达性**：主题图库支持方向键漫游（←→ 移一张、↑↓ 移一行、Home/End 首尾），跨「系统方案 / 我的主题」两段连续移动
- **更省电**：预览动画在窗口失焦后自动停表（切去别的应用不再空烧 CPU），最小化停表逻辑不变；删除 / 筛选 / 排序后保留的行会平滑滑动补位（180ms，尊重系统「减少动态效果」）
- 一批底层改进：状态徽标入场过渡、批量整理勾选口径收敛为可单测的纯函数、新增 4 个真机验证脚本

> 从 v0.4.0 升级：直接安装即可，主题、历史与设置全部保留。

### ❓ 常见问题

**Q：安装后系统光标没变化？**
A：光标切换只在**桌面版程序**里生效，浏览器里看不到效果。
本应用通过 `HKCU` 写槽位路径 + `SPI_SETCURSORS` 通知系统刷新，不写 `C:\Windows\Cursors`，无需管理员权限。

**Q：我的数据存在哪？卸载会删吗？**
A：主题与数据都在 `%LOCALAPPDATA%\CursorStudio\`（主题、历史、备份、日志）。
**卸载不删数据**，重装后主题还在。

**Q：从旧版本升级要做什么？**
A：直接安装新版即可，无需卸载。设置、主题与使用记录自动保留。

**Q：支持 macOS / Linux 吗？**
A：不支持。本应用依赖 Windows 注册表与光标 API，只在 Windows 上构建与运行。
