## 鼠标主题工具 v0.4.0

一个**不需要管理员权限**的 Windows 光标主题管理器：导入 `.zip` / `.themepack` / `.theme` 主题包 → 一键应用 → 管理 → 回溯上次用的那个。

### ✨ v0.4.0 更新了什么

- **导入时当场提醒重复**：把同一个包拖两次、或批量拖入时夹带已有的包，导入完成会提示「与《某某》内容完全相同」——不再只能事后到诊断中心才发现（不拦截，删不删由你）
- **主题多了也好找**：「我的主题」新增排序（最新 / 最早导入、按名称、按槽位完整度）与筛选（只看缺文件的、只看从未使用过的）
- **报障更容易**：程序开始写运行日志（数据目录 `logs\` 下，自动轮转），出问题时「设置 → 数据 → 诊断中心 → 打开日志目录」一键直达
- **更省内存**：修复长会话下预览缓存无限增长的问题；曾经读不到的光标文件恢复后，预览图会自动恢复，不再显示占位图到重启为止
- 一批底层改进：批量删除、备份恢复与右键菜单导入的稳定性加强，CI 新增前端单测门闸

> 从 v0.3.0 升级：直接安装即可，主题、历史与设置全部保留。

### ❓ 常见问题

**Q：安装后系统光标没变化？**
A：光标切换只在**桌面版程序**里生效，浏览器里看不到效果。
本应用通过 `HKCU` 写槽位路径 + `SPI_SETCURSORS` 通知系统刷新，不写 `C:\Windows\Cursors`，无需管理员权限。

**Q：我的数据存在哪？卸载会删吗？**
A：主题与数据都在 `%LOCALAPPDATA%\CursorStudio\`（主题、历史、备份、日志）。
**卸载不删数据**，重装后主题还在。

**Q：从旧版本升级要做什么？**
A：直接安装新版即可，无需卸载。设置、主题与使用记录自动保留。

**Q：支持 macOS / Linux 吗？**
A：不支持。本应用依赖 Windows 注册表与光标 API，只在 Windows 上构建与运行。
